# 3839 Review Fetcher

从 [好游快爆](https://www.3839.com/) 批量读取用户动态（游戏评价/论坛帖子/回复），支持在线可视化页面和多种格式导出。

## 在线可视化页面

无需安装任何环境，直接打开网页即可使用：

**[https://nanhua-7gd6q2h3cb2db2cb-1322713376.tcloudbaseapp.com/](https://nanhua-7gd6q2h3cb2db2cb-1322713376.tcloudbaseapp.com/)**

### 页面功能

- **输入 UID 或主页链接**：支持直接输入 UID（如 `20594033`）或粘贴完整主页链接
- **自定义读取数量**：1-100 条，按需读取
- **分类筛选**：全部 / 评价 / 回复 / 帖子，一键切换查看
- **实时统计**：总内容数、游戏评价数、评价游戏数、平均评分、评分分布、日期范围
- **搜索过滤**：按游戏名或内容关键词即时搜索
- **多格式导出**：CSV / JSON / HTML，按当前筛选分类导出
- **详情弹窗**：点击内容查看完整评价，含原始链接跳转
- **深色模式**：自动跟随系统主题

## 技术架构

### 部署方案

| 层 | 平台 | 方案 |
|---|---|---|
| 前端 | 腾讯云 CloudBase 云函数 | `web-index` 云函数返回 HTML 页面，通过 HTTP 路由 `/` 访问 |
| 后端 | 腾讯云 CloudBase 云函数 | `tcb-proxy` 云函数代理 3839 API，通过 HTTP 路由 `/api` 访问 |
| 外部 API | 3839.com | `api_user.php` 接口，云函数通过 HTTPS 转发 |

前端和后端均为腾讯云 CloudBase 云函数，通过 HTTP 路由分发请求，无需传统服务器。

### 安全措施

**后端 `tcb-proxy`：**
- 白名单机制：只允许 `ac=dynamic_home` 操作，拒绝其他 API 调用
- UID 验证：正则校验 `/^\d{1,20}$/`，防止注入
- 请求体长度限制：最大 500 字符，防止 DoS
- 参数重建：丢弃原始参数，仅使用验证过的字段构建请求

**前端 `web-index`：**
- XSS 防护：所有动态内容（游戏名、链接、日期等）均通过 `escapeHtml()` 转义
- 输入限制：读取数量前端 `min=1 max=100` + JS 钳制双重校验
- 链接安全：所有外链添加 `rel="noopener noreferrer"`

## Python 命令行版（备用）

如需离线使用或批量处理，可使用 Python 脚本：

### 环境要求

- Python 3.8+
- Windows / macOS / Linux

### 安装依赖

```bash
pip install requests openpyxl
```

### 基本用法

```bash
# 直接传入 UID
python fetch_reviews.py 20594033

# 传入用户主页链接
python fetch_reviews.py https://www.3839.com/zone/user/20594033

# 指定读取数量
python fetch_reviews.py 20594033 --count 100

# 指定输出文件名
python fetch_reviews.py 20594033 --count 500 --output "我的评价.xlsx"
```

### 如何获取 UID

在浏览器中打开好游快爆用户的主页，URL 最后的数字就是 UID：

```
https://www.3839.com/zone/user/20594033
                                   ^^^^^^^
                                   这就是 UID
```

## 工作原理

1. 前端发送 POST 请求到 `/api` 路由
2. `tcb-proxy` 云函数验证参数后，通过 HTTPS 转发到 3839 API
3. 使用 `last_id` 和 `cursor` 分页，每页返回 20 条
4. 前端解析返回的 JSON，自动识别动态类型：
   - `comment_game` → 游戏评价（含评分、游戏名）
   - `topci_reply` → 论坛帖子
   - `topci_reply_comment` → 论坛回复
5. 清理 HTML 标签，渲染到表格，支持分类筛选和导出

详细的 API 字段说明见 [docs/api-reference.md](docs/api-reference.md)。
